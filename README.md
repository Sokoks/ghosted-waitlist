# Ghosted Waitlist

Waitlist site na hrvatskom. Besplatni hosting: GitHub Pages.

**Live:** https://sokoks.github.io/ghosted-waitlist/

## Lokalno

Otvori `index.html` ili:

```bash
python3 -m http.server 5173
```

## Google Sheets

1. Napravi Google tablicu → Extensions → Apps Script
2. Zalijepi `google-apps-script.gs`
3. Deploy → Web app → Anyone
4. URL stavi u `config.js` kao `googleScriptUrl`
